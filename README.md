Entry for make.fun's [Absurd Micro-Startup Pitch-Off](https://make.fun/bounty/u-ricoxyz-absurd-micro-startup-pitch-off-12e33571) bounty ($2 in USDC).

## The pitch

> A micro-startup renting lazy agents whose only job is to sit in Zoom calls, nod, and type 'great point!' in chat — $5 a meeting, paid by teams that hate meetings.

## How it works

`main.py` (Python 3.13, stdlib only, no network, no wall clock) writes the
one-sentence pitch to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The program validates
the pitch against the competition gate first: 1–200 characters, exactly one
sentence, a single line, not only whitespace. Two runs produce byte-identical
output.
